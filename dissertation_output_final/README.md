# Dissertation Output (Final)

This directory contains the final dissertation LaTeX project.

## Structure

- `main.tex` — master document
- `chapters/chapter1.tex` ... `chapters/chapter6.tex` — chapter files

## Build

From repository root:

```bash
latexmk -pdf dissertation_output_final/main.tex
```

Output PDF will be generated as `dissertation_output_final/main.pdf`.
